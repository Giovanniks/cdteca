CDteca Pessoal — Grupo 5

O CDteca Pessoal é um projeto desenvolvido em linguagem C para ajudar o usuário a organizar sua coleção musical. Nele, é possível cadastrar músicas, álbuns e artistas, além de curtir músicas e consultar as favoritas e mais ouvidas.

O sistema é dividido em 4 módulos, cada um com sua própria struct, e o desenvolvimento foi distribuído entre os integrantes:

-Giovanni: Módulo de Álbuns e Módulo de Curtidas e Relatórios.

-Vinicius: Módulo de Músicas.

-Alan: Módulo de Artistas.

O objetivo do projeto é colocar em prática o que aprendemos nas aulas de programação em C, utilizando structs, funções, vetores, estruturas de repetição e arquivos CSV para armazenar os dados.

Tecnologias utilizadas: Linguagem C e Dev-C++.
